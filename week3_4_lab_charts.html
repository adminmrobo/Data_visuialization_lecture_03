실습 ② · Seaborn 고급 그래프 3장

실습 ②-1 · "비 오는 날 배달이 더 오래 걸리나?" — 바이올린 플롯

평균만 보면 차이가 묻힌다. 분포의 모양을 봐야 비 오는 날의 긴 꼬리가 보인다. delivery 주문만 보고, x축 weather(비/맑), y축 wait_min.

프롬프트 카드wait_min을 channel별로, weather(비/맑) 두 그룹으로 나눠 violinplot으로 그려줘. channel 3개(store/pickup_app/delivery) · weather 2개 · 전체 분포 확인. 한국어로 답해 주세요. 코드는 한 줄마다 한 문장으로 설명해 주세요. R 검사 3가지① x축이 channel로 그룹화되었나 ② weather(비/맑)로 갈라졌나 ③ y축 변수가 wait_min인가 — 하나라도 빠지면 프롬프트를 고친다.
Prompt cardDraw a violinplot of wait_min by channel, split by weather (rainy vs sunny). Three channel groups (store/pickup_app/delivery) · two weather groups · show the full distribution. Answer in English. Explain each line of code in one short sentence.
提示卡画一张小提琴图，横轴是channel（三个：store/pickup_app/delivery），按weather拆成两组（雨天/晴天），看wait_min的分布。 三个channel组 · 两组weather · 展示完整分布。 请用中文回答。每行代码用一句话解释。

읽기 — 비 오는 날이 더 느리고, 꼬리가 길다

비 오는 날의 꼬리(위쪽 가는 부분)가 맑은 날보다 길다 — 대부분은 평범하지만 가끔 아주 오래 기다리는 날이 있다. 박스플롯은 가운데만 보여주고, 바이올린은 전체 분포를 보여준다. 한 문장 결론 — "비 오는 날이 더 느리고, 더 불안정하다." 질문에 "평균만 보면" 긴 꼬리를 놓친다.

실습 ②-2 · "숫자들이 함께 움직이나?" — 상관 히트맵

숫자가 많아지면 먼저 이 한마디 — "같이 움직이나, 반대로 움직이나?" 대기 시간이 길어지면 평점이 내려가나? 당도가 오르면 가격이 따라 움직이나? 히트맵 한 장에 양수 · 음수가 색으로 갈린다.

프롬프트 카드sugar_pct · price_krw · wait_min · rating 네 컬럼으로 상관 히트맵 그려줘. 칸마다 숫자 출력 · 음수는 앰버 · 양수는 인디고 · 0은 흰색. 한국어로 답해 주세요. 코드는 한 줄마다 한 문장으로 설명해 주세요. 주의AI가 그린 히트맵에는 숫자가 빠진 경우가 많다 — "값도 칸에 써 줘"라고 꼭 더한다. 색만 보면 애매하다.
Prompt cardMake a correlation heatmap of four columns: sugar_pct, price_krw, wait_min, rating. Print the value in each cell. Negative = amber, positive = indigo, zero = white. Answer in English. Explain each line of code in one short sentence.
提示卡画一张相关热力图，列出sugar_pct、price_krw、wait_min、rating四个变量。 每个格子里写相关系数，正负用颜色分开，-1用琥珀、+1用靛蓝、0用白。 请用中文回答。每行代码用一句话解释。

읽기 — 오래 기다릴수록 평점이 내려간다

가장 기억할 한 쌍: wait_min과 rating — 값이 음수, 색이 앰버. 양 · 음이 한눈에 갈리는 것이 히트맵의 장점이다. 4열이면 충분하다 — 열이 더 많으면 먼저 골라야 한다.

실습 ②-3 · "한 주 중 언제가 제일 바쁜가?" — 요일 × 시간 히트맵

근무표 짜기 · 쿠폰 내기 · 마케팅 날 잡기 — 모두 이 질문에서 시작한다. x축은 시간(10~23시 영업시간 14칸), y축은 요일, 칸 색으로 바쁨을 판단한다.

프롬프트 카드weekday(월~일) × hour(10~23) 주문 수 히트맵. 가장 붐비던 칸은 앰버로. 흰→인디고 그라데이션. 주문 적을수록 색은 연해짐. 한국어로 답해 주세요. 코드는 한 줄마다 한 문장으로 설명해 주세요. 오류 나면오류 메시지를 그대로 붙여 되묻거나, 표현을 바꿔 한 번 다시 묻는다. AI를 위해 대신 추측하지 않는다. 보고용 오류는 재현 가능해야 한다 — ① 전체 코드 ② 오류 화면이나 텍스트 ③ 원했던 그림, 한 묶음으로.
Prompt cardHeatmap of order count by weekday (Mon-Sun) × hour (10-23). Highlight the busiest cell with amber. White → indigo ramp. Fewer orders = lighter cells. Answer in English. Explain each line of code in one short sentence.
提示卡画一张weekday（周一到周日）× hour（10-23）的订单数热力图。 最忙的一格用琥珀高亮；颜色从白到靛蓝；颜色浅说明那天那阵子很闲。 请用中文回答。每行代码用一句话解释。

읽기 — 금요일 저녁 8시, 칸 하나가 제일 밝다

한 문장 결론 — "금요일 20시가 최고 피크라 근무표를 더 넣어야 한다." 이런 그래프를 읽기 전에 한 박자 멈추는 습관 — 가장 밝은 칸에 동그라미를 치고 "이것이 사실인가?"부터 묻는다.
